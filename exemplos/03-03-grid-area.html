Exemplo 2: Layout com áreas nomeadas

grid-template-areas + grid-area
Header
Sidebar
Navegação / filtros
Content
Área principal
Aside
Extras
Footer
.layout {
  display:grid;
  grid-template-columns:200px 1fr 200px;
  grid-template-rows:80px 1fr 60px;
  grid-template-areas:
    "header header header"
    "sidebar content aside"
    "footer footer footer";
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
.aside   { grid-area: aside; }
.footer  { grid-area: footer; }

Exemplo 3: Card com áreas nomeadas

Componente reusável usando grid-template-areas
IMG
Título do Card
Descrição breve do conteúdo do card demonstrando organização com áreas nomeadas, fácil de rearranjar.
Ação
.card {
  display:grid;
  grid-template-columns:120px 1fr;
  grid-template-rows:auto 1fr auto;
  grid-template-areas:
    "imagem titulo"
    "imagem descricao"
    "imagem botao";
}
.card-imagem    { grid-area: imagem; }
.card-titulo    { grid-area: titulo; }
.card-descricao { grid-area: descricao; }
.card-botao     { grid-area: botao; }
